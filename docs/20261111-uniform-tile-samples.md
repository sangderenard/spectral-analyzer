# Uniform tiled sample targets, 2026-11-11 UTC

The real 2048x2048, 2x oversampled photo completed all sixteen 1024x1024 sensor windows with a 60-second budget per tile. Actual samples per internal pixel were 33,24,22,29,25,4,4,25,13,5,5,14,11,4,4,12. Equal time produced an 8.25x work imbalance. This is not evidence of mismatched tile brightness: the existing assembler already divides each tile by its own sample count, averages the complete linear image (including filter support across window boundaries), and uses one global display white and curve.

Added optional photo.samplesPerOutputPixel / wire samples_per_output_pixel, integer 1..65536, through the existing agent product, photo packer, authenticated canonical job config, tile plan and owned worker. It selects the existing tiled RGB still path. Each internal pixel gets ceil(target / oversampling**2) complete samples. Requested and effective output-pixel counts are recorded, including rounding. Each tile ignores the legacy time stop in this mode and assembly rejects incomplete sample targets. An explicit debug epoch cap fails rather than falsely completes an undersampled image.

Omission preserves legacy seconds behavior and canonical config identity. No shader, camera timing, scene or sensor-weighting change, overlap/feather blur, gain matching, substitute renderer or extra GPU run. Equal camera sample counts are not equal variance or proof of physical convergence. The frozen legacy forward field is unchanged.

The initial uniform-target regression cases failed against the unmodified source (14 failures), while the pre-change legacy tile/coordinate/lifecycle gate passed 36 tests. Final gates passed: 60 Spectral CPU tests (tile planning, monolithic equality at all four oversampling factors, coordinates, real worker lifecycle with controlled accumulators), 73 Turing tests (admission, photo jobs, agent products and camera sequences), Node tile payload checks and actual Node scene-to-MRP1 checks. Python compilation and scoped diff checks passed. Guestbook validation passed without applying archive changes. No new GPU result is claimed. This change is source-only and was made after the publication worker released its backend reload freeze. It is not deployed.
